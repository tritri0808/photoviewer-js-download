### 🔹 Bước 1: Mở cửa sổ Console (F12)
Tại giao diện trang web, bạn mở công cụ nhà phát triển bằng 1 trong 2 cách:
* **Cách 1:** Nhấn phím `F12` (hoặc `Fn + F12` tùy máy) trên bàn phím.
* **Cách 2:** Click chuột phải vào khoảng trống bất kỳ trên màn hình $\rightarrow$ Chọn **Kiểm tra (Inspect)**.

*Sau đó, nhìn lên thanh menu của bảng vừa xuất hiện và chọn tab **Console** (Điều khiển).*

### 🔹 Bước 2: Dán Code và Chạy
Cửa sổ Console hiện ra, bạn hãy copy toàn bộ đoạn mã JavaScript ở mục dưới đây, dán (`Ctrl + V` hoặc `Cmd + V`) vào vùng nhập liệu của Console, rồi nhấn **Enter**.
